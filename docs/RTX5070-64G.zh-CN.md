# RTX 5070 12GB + 64GB：我的现阶段自用配置

**这就是我现阶段在单卡 RTX 5070 12GB + 64GB RAM 上调出来、最适合我自己工作流的配置。** 不是全世界最优，也不是所有机器直接照抄都会稳定。

显存专家工作时，我观察到过 **100+ token/s**。单卡 5070 加 64GB 能破百，我觉得相当快。这里记录的是作者使用体验，不是本次发布重新跑出的标准 benchmark，不保证全程/所有提示词破百，也不是把 GPU 百分比或 DFlash2 接受率当生成速度。

## 如何套用

1. 安装自己的 Strata Control/匹配 CUDA 引擎，准备模型 GGUF、pack、tokenizer、基础专家路由表、视觉头和匹配的 tuned DFlash2 pack；本仓库不下载、不附带这些资产。
2. 复制 `conf/launcher.example.json` 为私有的 `conf/launcher.json`，改成本机 Control/engine/model profile 路径。优先引用你已经由 Strata 正式生成的 profile。`conf/profiles/*.example.json` 是可检查的路径示例，不是假装模型已安装。
3. `node launcher.mjs doctor iq4xsv31-vision`，然后 `check`、`prepare` 查看最终清单。不要为了过检查删掉锁、降低保护或停止别人任务。
4. Git for Windows + Node.js 22+ 就绪后，打开 `Strata-Panel.cmd`。GUI 和 CLI 的模型参数共享 `conf/launcher.json`；保存不改变当前运行模型，需明确重启才生效。
5. 资源页先只读扫描。需要关闭应用时只勾所需项；强制模式需确认，文件/下载可能丢失。Explorer 单独操作，异常恢复：Ctrl+Shift+Esc → 运行新任务 → explorer.exe。

## 稳定性与质量边界

- 先保证能跑，再比较速度。168 MiB 不是通用推荐保留量；显存余量太小可能触发 WDDM 换页。可从更保守的 512–1024 MiB 试起，但这不是作者快照原值。
- `pinned-memory-exhausted` 是页锁定 RAM 申请失败，不是“分页文件还剩很多就一定够”。可先把 prefill 设成 `auto:8192`，仍失败再降低专家 RAM，例如 42 GiB；不要盲目增加缓存。
- 破百受任务、缓存、草稿接受率、后台显存、上下文长度和输出类型影响。比较时记录实际 PP、TG、TTFT、accepted/offered、expert hit、读盘和峰值资源，不拿几 token 的短答当基准。
- 显存扫描使用 NVML 整卡和 WDDM 进程计数，两者不能简单相加/相减。停止 Explorer 可能只省几十 MiB；拔显示器不保证释放所有显存。
- 本次服务接口未运行时，发布只导出保存值，不声称这些值已在一个正在运行的实例全部生效，也未重跑性能测试。
- Pi 程序、技能、监视/压缩/watchdog 扩展按用户自己的安装配置。私有会话、指令、模型、凭据、恢复预算和真实内网地址不在发布包中。
